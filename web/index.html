Tiered Authorization (HITL) Autonomous execution for read/simulate analytics; physical grid state changes (e.g., FLISR) or financial bids require human-in-the-loop operator confirmation.
🚀 Key Architectural Pillars
  • Strict Single-Purpose Scope (113 Production Agents across 10 Business Domains): Universal Master Orchestrator + 10 specialized industry business domains ensuring atomic responsibilities, zero bloat, and low cognitive load.
  • The Critic Protocol (Automated Gatekeeper + HITL): Every specialized agent contains an internal Critic sub-agent that audits safety guardrails and prevents hallucinated metrics before any response leaves the agent boundary.
  • Modular Prompt Composition: Dynamic runtime assembly of 4 modular prompt layers (persona.md, business_rules.md, output_format.md, and safety_guardrails.md) for maintainable governance.
  • Enterprise Lakehouse Isolation: Dedicated per-agent BigQuery tables and least-privilege IAM service accounts ensuring zero cross-tenant contamination.
  • Dual-Tier High-Performance Delivery: Native byte-range streaming bundled into Cloud Run Nginx behind Google IAP eliminates cross-origin cookie friction for corporate @google.com users, backed by authenticated GCS fallback.
